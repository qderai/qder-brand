# Qder brand

The Qder logo, colours and how to use them. For press, partners and anyone writing about Qder.

## Logo

| File | Use |
|---|---|
| `logo/qder-lockup-ltr-cobalt.svg` (`.png`) | The default: on white or light backgrounds |
| `logo/qder-lockup-ltr-white.svg` | On cobalt, dark or photographic backgrounds |
| `logo/qder-lockup-ltr-black.svg` | One-colour print |
| `mark/qder-mark-*.svg` | The mark alone (two bubbles), where the name is already written nearby or space is square |
| `avatar/qder-avatar-*.svg` (`.png`) | Profile pictures and app icons |

**The mark is always on the LEFT of "Qder.ai"**, in every language, including Hebrew and right-to-left pages.
Do not mirror the lockup for RTL layouts. Inside an RTL page, place the lockup in a left-to-right box.

- Keep clear space around the logo of at least half the mark's width on every side.
- Don't recolour it (cobalt, white or black only), stretch it, rotate it, outline it or add effects.
- The mark is two bubbles, the guest's and the waiter's. In cobalt it uses three solid cobalts (below); in white, three strengths of white; in black, one colour with a gap cut around the front bubble.
- Don't put the cobalt logo on a busy or mid-tone background; use the white one.
- The name is written **Qder** (or **Qder.ai** for the product site); in Hebrew, **קיודר**.

## Colours

| Name | Hex | Use |
|---|---|---|
| Cobalt | `#0B3FD9` | The brand colour: logo, primary buttons, links |
| Cobalt press | `#0830A8` | Pressed and hover states |
| Cobalt lift | `#3767ED` | Cobalt on dark backgrounds |
| Mark back | `#8AA5F2` | The back bubble of the cobalt mark |
| Mark front | `#3D68E6` | The front bubble of the cobalt mark (the overlap is Cobalt) |
| Cobalt wash | `#EDF2FE` | Light tinted surfaces |
| Ink | `#080D1C` | Headings and body text on light backgrounds |
| Body | `#4A5570` | Secondary text |
| Line | `#E4E9F4` | Hairlines and borders |
| Background | `#FFFFFF` / `#F7F9FE` | Pages and alternate sections |
